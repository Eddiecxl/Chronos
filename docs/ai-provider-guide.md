# AI 服务选择与连续游玩

《落樱仙途》默认使用 Groq `qwen/qwen3.8-27b`。每次 AI 行动只发一份精简场景状态并只请求一次生成：Qwen 使用快速的 instruct 模式和第三人称叙事，以角色姓名或“他”指代主角；其他模型仍保持第一人称规则。这样不会因人称校验或修正剧情额外消耗一次免费额度。

| OpenAI `gpt-4.1-mini` | 低成本、低延迟候选；OpenAI 入口默认 | 0.40 / 1.60 |

所有 API 都有额度和限流；没有一种免费 AI 可以承诺无限、永不限流。Groq 免费额度按组织共享，因此同一个 Key 被多人或别的程序使用时也会影响游戏。Qwen 3.8 的官方限额可在 Groq 控制台查看；游戏会显示上游的 Retry-After，等待结束后再点击重试即可，不会在后台连发。

按每回合 2,500 输入 + 700 输出 token、不含缓存优惠和修正请求估算，100 回合分别约为 **$0.21 / $0.50 / $1.34**。长记忆、修正、更多正文会增加实际用量。这里只是成本估算，不是付款或充值操作。

## 如何使用

个人测试：游戏 → AI 设置 → OpenAI → 自己的 API Key。官方 Base URL `https://api.openai.com/v1` 已填好，先用 `gpt-4.1-mini`。Key 只在当前页面内存保留、不写入存档或 localStorage；不同服务商分别保存到本页关闭。请求直接发给所选官方 API（浏览器需允许跨域请求）。不要使用别人的 Key，不要把 Key 写进仓库或聊天记录。

正式站点使用后端：在 Render Environment 设置 `GROQ_API_KEY` 和可选 `GROQ_MODEL=qwen/qwen3.8-27b`，部署后玩家选“Chronos 网站额度”。服务器的 Key 不传给浏览器。网站模式依然有每账户保护限额；个人模式不使用网站共享额度。需要切换模型时，在游戏 AI 设置中选择 Groq 的另一个模型即可；只影响下一回合。ChatGPT 会员与 API 账单分开，不能用会员登录令牌替代 API Key。

切换服务商或模型只影响下一次请求，原有旅程与记忆保留；不自动切回本地故事，也不偷偷切换到付费模型。若以前公开过 Key，请在对应控制台轮换。

## 本次性能修正

- 默认 Groq 模型改为 Qwen 3.8。Qwen 回合只发送两条消息（规则 + 精简状态/记忆/最近一回合），不用旧路径的多份长场景契约与长历史。
- Qwen 固定 instruct 档、较小输出预算和 JSON 对象响应；同一个回合校验未通过或上游临时忙碌时均不会自动重发。玩家输入和存档保持不变，可修改输入后再试。
- Qwen 采用第三人称验证和提交；模型自然写“照月”或“他”不会被第一人称校验错误拦住，也不会因此浪费第二次调用。
- 余额不足、凭据问题、模型无权限、站点保护、上游限流、内容因果校验分别反馈。
- 保留真实 Retry-After（包括长于 30 秒、HTTP 日期及 Gemini RetryInfo），冷却期间不再次发送相同凭据/模型请求；503 明确要求等待时同样遵守。
- 不因空的可选地点字段要求重写剧情；世界事实的可选记忆注释若是唯一问题，可移除没有正文依据的注释，再跑全部校验。不会补造剧情、掩盖未发现角色或放弃有效推进要求。
- “我必须立刻决定”与“我决定加入”区分，避免把尚未发生的决定误判为替玩家选择；首次苏醒不强行推进时间，但开篇标记不可重复用于后续回合。

## 验收与已知限制

此前 GPT-OSS 的 2–4 倍长上下文、校准重试和 Qwen 第一人称拒绝都会很快触发 Groq 免费层的每分钟 token 限额；这些不再用于 Qwen 默认路径。当前代码测试覆盖精简两消息请求、单次调用、第三人称提交、限流冷却、输入保留、系统暂停、装备与剧情状态。

真实模型质量和任何账户的剩余额度仍由上游服务决定。若一开始就收到 429，请等待游戏提示的时间，或确认同一 Groq Key 没有被其他应用同时消耗；不要连续点击重试。

验收脚本 `scripts/game-ai-benchmark.mjs` 支持 `--journey`（开篇 + 最多 8 个世界回合），首个失败即停止。`GAME_BENCH_MODEL` 指定模型，`GAME_BENCH_READING_MS` 可设置每回合前的阅读时间，默认 0；报告明确显示阅读时间，不能把带间隔的结果说成无间隔压力测试。使用真实 Key 会消耗对应 API 额度，脚本不打印 Key、不操作玩家存档。

发布新仓库之前，仍需要用有可用额度的目标服务完成连续场景、记忆召回、第一人称、系统暂停及章节推进验收。尚未满足此门槛。
